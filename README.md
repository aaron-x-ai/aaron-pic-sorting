# 🗂️ aaron-pic-sorting

> 个人 IP 素材智能整理助手：自动识别、分类归档、规范命名，让你的图片素材从此井井有条。

---

## ✨ 功能特点

- **📸 智能分类**：AI Vision 自动识别图片内容，按「工作 / 生活 / 我与ai / 2026」四大目录分类
- **🏷️ 规范命名**：自动提取中文标签，统一重命名为 `20260405-讲课-清华.jpg`
- **⏰ 双模触发**：每天定时自动整理 + 聊天发图即时整理
- **📝 完整日志**：单一日志文件追加，处理记录一目了然
- **🔄 自动去重**：基于 MD5 指纹，同一文件只整理一次
- **🧼 自动清理**：30 天以上的已处理目录自动删除，保持整洁

## 🎯 第一次使用（必读）

**安装完成后，对 AI 说以下任意一句话即可启动：**

> **"配置素材管理"**

AI 会带你走完 4 步交互式配置，确认素材目录、整理目录、定时时间、分类名称。

**配置完成后，你可以：**
- 说 **"整理素材"** 手动触发整理
- 发一张图片并说 **"整理这张素材"** 单张即时整理
- 把图片放进素材目录，等待每天自动整理

## ⚙️ 配置说明

配置文仴位于：`~/.config/aaron-pic-sorting/config.yaml`

主要配置项：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `paths.source_root` | 待整理素材目录 | `/Users/mac/Downloads/IP素材` |
| `paths.target_root` | 整理后归档目录 | `/Users/mac/Documents/...` |
| `schedule.enabled` | 是否开启定时整理 | `true` |
| `schedule.cron` | Cron 表达式 | `0 22 * * *` (每天 22:00) |
| `categories.mapping` | 分类目录映射 | 工作 / 生活 / 我与ai / 2026 |
| `processing.retention_days` | 已处理目录保留天数 | 30 天 |

直接编辑此 YAML 文件可实现高级自定义，修改后立即生效，无需重启。

## 📜 日志格式

日志文件位于素材目录下的 `aaron-pic-sorting.log`，每行一条：

```
[2026-04-27 22:00:15] SUCCESS | IMG_1234.heic | 分类:工作 | 目标:20260405-讲课-清华.heic
[2026-04-27 22:00:18] SKIP    | IMG_1235.jpg  | 原因:MD5已存在
[2026-04-27 22:00:22] ERROR   | IMG_1236.raw  | 原因:Vision分析失败(网络超时)
```

## 🛠️ 技术细节

- **支持格式**：jpg, jpeg, png, webp, gif, heic, raw, tif, tiff
- **日期优先级**：EXIF 拍摄日期 → 文件修改时间 → 处理当天日期
- **冲突处理**：目标目录已存在同名文件时，自动追加序号（`_1`, `_2`）
- **去重方式**：基于文件 MD5 指纹，存储在 SQLite 数据库中

---

## 💡 Tips

1. **定时整理 vs 即时整理**：建议晚上放图、白天累积，晚上 22:00 自动一次性整理；重要图片用聊天即时整理。
2. **复用配置**：说"配置素材管理"可随时修改目录、时间、分类，无需重装。
3. **重置配置**：说"重置素材整理配置"可完全清空当前设置，重新走首次引导。
